Changes to the upstream program
-------------------------------

Based on upstream commit bb88594.

2026-10-10
  - Runtime branding: the product name comes from AURA_BRAND_NAME (neutral
    default "Admin Panel"); favicon.ico, apple-touch-icon.png, logo.svg and
    manifest.json can be replaced at runtime by files in AURA_BRAND_DIR
    (default /brand). English strings that named the product use the
    runtime name.
  - Removed the LibreChat and ClickHouse logos and the ClickHouse favicon;
    added a neutral default logo, favicon and touch icon.
  - Admin tools section in the sidebar, configured by AURA_ADMIN_LINKS and
    AURA_ADMIN_LINKS_TITLE and shown only to signed-in admins; embedded
    tools open under /tools/<id>. The frame-src directive of the
    Content-Security-Policy admits them by source kind (https:, loopback
    or same origin), so the header never names an embedded host.
  - Legal notice footer on every page, an "About and license" card on the
    Help page, and this NOTICE file (also served as /NOTICE.txt, with the
    license as /LICENSE.txt).
  - The page layout leaves room for the footer below the content.
  - Docker image: build argument AURA_COMMIT for the source link, OCI
    labels, LICENSE and NOTICE copied into the image.
  - Continuous integration for the aura branch, which also builds the app
    and the image without publishing them; removed the upstream image
    publishing workflow.
  - Operator notes for the added settings in AURA.md.
  - Signed one-minute pass for same-origin embedded tools: with
    AURA_TOOLS_PASS_SECRET set, the panel adds aura_pass=<pass> to the
    frame address of an embed entry with a same-origin path, for a
    signed-in admin; admin links accept an optional audience field.
  - Embedded tools may show confirm and prompt dialogs and leave the frame
    for the top window on a user click; a "Reload frame" control loads the
    frame again with a fresh pass.
  - Upgrade guide for new upstream releases in UPGRADING-AURA.md and a
    short fork section at the top of README.md.
